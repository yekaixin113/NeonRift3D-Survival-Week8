# History provenance

This repository was created on 11 October 2026 to organise the previously completed Week 8 game changes into reviewable feature and debug branches.

The baseline restores the saved original Game3D, SDK configuration, README and ARCHITECTURE. Combat classes and scenes come from the supplied project and were unchanged by the survival work. Intermediate commits reconstruct feature boundaries from the saved code, initial implementation script and annotated change report. The final gameplay source matches the delivered fixed project.

Commit dates record this reconstruction, not the dates of the earlier development. Member A and Member B are responsibility labels from the plan; commits use the currently configured Git identity and do not assert that two different people authored them. Team names and acceptance of the proposed split must be supplied by the group.

All branches are retained and merged with explicit two-parent merge commits. No backdating, invented reviews or historical pull requests are used.
